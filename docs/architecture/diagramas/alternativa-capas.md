# Alternativa descartada: Monolito en Capas

El Monolito en Capas obtuvo el segundo mejor puntaje en la matriz de decisión (3.75).
Aunque ofrece simplicidad de desarrollo, bajo costo de infraestructura y permite
cumplir con el plazo del MVP, fue descartado frente al Monolito Modular porque
ofrece menor aislamiento entre dominios y puede aumentar el acoplamiento entre
capas a medida que el sistema evoluciona. Esto dificulta cumplir el atributo
crítico de modificabilidad de EcoRecicla AQP (QA-01).
