# E4: docstrings para EcoRecicla AQP

Este directorio contiene el contrato, ocho casos basados en funciones del repositorio, tres versiones del prompt, las respuestas guardadas y las evaluaciones de la Tarea B del Lab09.

- `contrato.json`, `casos.yaml`: formato de salida y dataset con parámetros esperados.
- `v1.txt`, `v2.txt`, `v3.txt`: prompts iterativos.
- `promptfooconfig-v1.yaml`, `promptfooconfig-v2.yaml`, `promptfooconfig-v3.yaml`: configuración de Promptfoo y seis aserciones.
- `grabaciones/`: respuestas que reproduce el proveedor local.
- `resultados-v1.json`, `resultados-v2.json`, `resultados-v3.json`: resultados obtenidos.
- `iteraciones.md`: análisis de fallos y cambios entre versiones.

La versión v3 pasó los ocho casos del conjunto registrado. Esa cifra describe el dataset de esta evaluación; no garantiza que cualquier función o respuesta futura pase.
